# Reference only — never merge this branch

A snapshot (2026-11-09) of CNCT's hosted chat page, exactly as production serves it at
`https://app.doo.ooo/chat-assets/chat.js`, `/chat-assets/chat.css` and `/chat/<publicKey>`.

It is here so an environment that cannot reach app.doo.ooo can still read the reference
implementation that `docs/chat-ui/SPEC.md` points to. Read it and port behaviour; do not copy it
into the SDK, and do not merge this branch into anything.
